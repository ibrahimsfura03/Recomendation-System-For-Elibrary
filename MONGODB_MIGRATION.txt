HOW TO START
============

1. Ensure MongoDB is running:

   source venvibrahim/bin/activate

3. Start Flask app:
   python app.py

4. Access web interface:
   http://localhost:5000

5. Login:
   - Admin: http://localhost:5000/admin/login
   - User: http://localhost:5000/login
   - Author: http://localhost:5000/author/login
